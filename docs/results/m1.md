## Analyze

- The first anonymization run failed its own rule: "smallest quasi-identifier group has 3
  customers, need 5". With 250 customers spread over 5 countries and 6 decades, postal prefixes
  made almost every group unique. Root cause: generalization alone cannot reach k on a small
  table. Fix: suppress the postal prefix, then the country, then the remaining customers in small
  groups (standard k-anonymity suppression), and report each count.
- The first leak-scan draft matched every raw value as a substring, which would flag a numeric
  postal code that equals an order amount. Short values (under 8 characters) now match only as a
  whole JSON string; a test covers both directions.

## Improve

- The anonymizer now always produces groups of at least k and says what it gave up to get there.
- The API refuses any dataset that is not in the anonymized shape, so a raw export cannot reach an
  environment by mistake (decode error 400 for raw fields, 422 for personal-looking values).

## Control

- CI `ci` workflow: gofmt, go vet, helm lint, tests with the race detector, the leak scan, the chart
  policy and govulncheck on every push and pull request.
- `TestCommittedSeedMatchesRegeneration` fails if the raw fixture or the chart's seed drift from
  `make seed`.
- `values.schema.json` pins image names, `pullPolicy: Never`, the tag pattern and resource shapes.
- The `ephemeral-env` workflow prints `::notice` with up and total seconds, or `::error` with the
  failed step and whether teardown ran.
